How to use this in delivery

  1. Start from the process or candidate action being built.
  2. Identify the controls that can permit, block, redirect or require human review.
  3. Validate the external basis against the actual insurer, product, jurisdiction and policy context.
  4. Turn the validated requirement into a versioned rule, timer, human task, data requirement or test.
  5. Link the implementation artefact back to the control ID so later regulatory changes can be impact-assessed.
